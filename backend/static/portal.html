③ 嵌入域名白名单（Origin）

配置后只有这些域名能加载你的客服浮窗（协议+域名+端口，如 https://www.example.com）。 留空 = 宽松模式（本地联调阶段建议留空，上线前务必配置）。

④ 后端 API 对接（可选）

你的平台/APP 后端可以用 sk_ 密钥直接调用开放 API：推送数据、创建会话、发消息拿回复。

# 推送商品（upsert by sku）
curl -X POST {ORIGIN}/api/v1/products \
  -H "Authorization: Bearer sk_…" -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"P-001","name":"咖啡豆","price":128,"category":"食品"}]}'

# 推送订单（自动按 user_external_id 绑定/创建顾客）
curl -X POST {ORIGIN}/api/v1/orders \
  -H "Authorization: Bearer sk_…" -H "Content-Type: application/json" \
  -d '{"items":[{"order_no":"SO-9","sku":"P-001","user_external_id":"member-42","amount":128,"status":"paid"}]}'

# API 会话：发一条消息，拿完整 AI 回复（非流式）
curl -X POST {ORIGIN}/api/v1/sessions -H "Authorization: Bearer sk_…" -d '{}'
curl -X POST {ORIGIN}/api/v1/sessions/{sid}/messages -H "Authorization: Bearer sk_…" \
  -d '{"content":"查一下订单 SO-9"}'

CSV 批量导入

上传商品或订单 CSV。文件名包含 "products" 或 "orders" 决定导入类型（如 shop-products.csv）。 已存在的 sku / order_no 会被更新（upsert），不会重复创建。

products 列：sku, name, price, category

为什么需要商品与订单数据？

AI 客服的两大硬能力都建立在数据上：查订单（顾客问"我的快递到哪了"，订单+物流卡片直接回答）、 办退款（基于订单金额做风险评分与审批路由）。数据只增不改真相：CSV 用来批量初始化， API 推送用来实时同步。所有数据仅在你的租户内可见。
