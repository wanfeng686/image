API 密钥（sk_）

你的后端可用 sk_ 调用开放 API：推送数据、创建会话、发消息拿回复。 ⚠️ 服务端密钥，只能用在你的后端，不要放进网页/APP 前端。

API 密钥 
# 推送商品（upsert by sku）
curl -X POST {ORIGIN}/api/v1/products \
  -H "Authorization: Bearer sk_…" -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"P-001","name":"咖啡豆","price":128}]}'

# 推送订单（自动按 user_external_id 绑定/创建顾客）
curl -X POST {ORIGIN}/api/v1/orders \
  -H "Authorization: Bearer sk_…" -H "Content-Type: application/json" \
  -d '{"items":[{"order_no":"SO-9","sku":"P-001","user_external_id":"member-42","amount":128,"status":"paid"}]}'

推荐 🔌 官方 API 接入

在平台开放平台申请的应用凭据（client_id / secret）。合规稳定、官方支持， 需要完成商家授权后补填 access_token。

🤖 浏览器托管（RPA）

没有开放平台资质也能接入：提供店铺账号，由我们的托管浏览器登录商家后台 收发消息。非官方通道，详见风险提示。

⚠️ RPA 模式风险知情同意
RPA 通过浏览器自动化操作你的商家后台，不符合平台官方服务协议，存在被平台 限流、限制功能甚至封禁店铺的风险。请确认你已知悉并自愿承担该风险。
